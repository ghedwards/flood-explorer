Desktop preview of Flood Explorer. Download the installer for your computer:

- macOS Apple Silicon (M1 and newer): `aarch64.dmg`.
- macOS Intel: `x64.dmg`.
- Windows 64-bit: `x64-setup.exe`.
- Linux 64-bit: `.deb` for Debian/Ubuntu, or `.AppImage`.

The app includes its viewer, flood engine, broker and national gauge catalogue.
New terrain, live readings and external map layers require internet access.
Optional feeds may require API keys in Settings. No API keys are bundled.

These are preview builds. macOS builds are ad-hoc signed unless the release
maintainer has configured Apple signing and notarization credentials. Windows
builds are unsigned. Operating systems may warn when installing them.

`SHA256SUMS.txt` contains installer checksums. Automatic updates are not enabled;
download a newer installer from this releases page when available.

This is a screening model. Do not use it for emergency or property decisions.
